# MediaDock Releases

MediaDock is a Windows desktop media downloader.

## Downloads

Download the installer from the [Releases page](https://github.com/sriniketh-alt/mediadock-releases/releases).

## Installation

1. Download the Windows installer.
2. Run the installer and follow the setup instructions.
3. Launch MediaDock from the Start menu.
